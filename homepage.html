About HolDex

The High-Velocity Terminal for Solana Assets

Core Philosophy

HolDex is built for traders who demand raw speed and absolute truth. We provide a terminal-grade interface that cuts through the clutter, now enhanced with Daily Holder Tracking and deep historical analysis.

We prioritize community verification and on-chain data integrity. Our proprietary indexing engine snapshots liquidity pools directly from the Solana RPC, ensuring you see price action as it happens.

Direct RPC Sync

No third-party delays. We index Raydium and Pump.fun directly.

K-Score Protocol

Community Verified

Zero Bloat

No ads. No trackers. Just data. Built for maximum performance on any device.

HolDex API Documentation

v1.0 Public Endpoint

Authentication

HolDex uses API keys for authentication. Include your key in the request header:

x-api-key: YOUR_KEY_HERE

Standard Rate Limit: 1,000 requests/day per key.

GET /api/tokens

Fetch a paginated list of top performing tokens.

// Response { "success": true, "tokens": [ { "mint": "So111...", "ticker": "SOL", "priceUsd": 150.2, ... } ] }
GET /api/token/:mint

Get detailed metadata, K-Score, and pool info for a specific token.

GET /api/token/:mint/candles

Fetch OHLCV data. Params: resolution (5, 60, D), from, to (unix timestamp).

K-Score Explained

Our proprietary metric for analyzing token health:

  • Holder Distribution: Are coins spread widely or concentrated?
  • Velocity: Is the token being traded actively or stagnant?
  • Longevity: How long have holders held their positions?

Higher scores indicate stronger community conviction.

How HolDex Works

Auto-Discovery

We listen to the Solana blockchain. New pools on Raydium & Pump.fun are indexed instantly once they hit significant volume.

Instant Search

Paste any CA (Contract Address) into the search bar to force-index a token instantly, regardless of volume.

Community Verification

Devs can update social links via the Update tab. We verify these on-chain to give the green checkmark.
