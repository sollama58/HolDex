API Documentation

HolDex REST API v1.0

Authentication

API keys are issued by admin. Include your key in the request header:

x-api-key: YOUR_API_KEY
Public endpoints (marked below) don't require authentication but have stricter rate limits.

Your API Keys

Base URL

https://asdev-backend.onrender.com/api

Public Endpoints

GET /tokens/public No Auth

Paginated list of all tokens with K-Score data.

Query Parameters:
page - Page number (default: 1)
limit - Results per page (max: 100)
sort - kscore, mcap, volume, price, holders
order - asc or desc
filter - verified (only verified tokens)
search - Search by name/symbol/mint
GET /token/:mint/public No Auth

Full token data including K-Score, conviction breakdown, and market data.

{
  "mint": "...",
  "name": "Token Name",
  "symbol": "TKN",
  "priceUsd": 0.001234,
  "marketCap": 1234567,
  "holders": 500,
  "kScore": 72,
  "creditRating": "BB+",
  "conviction": {
    "score": 75,
    "accumulators": 8,
    "holders": 6,
    "reducers": 4,
    "extractors": 2
  }
}
GET /token/:mint/top-holders/public No Auth

Top 20 holders with conviction role classification.

{
  "holders": [{
    "address": "5yBE...",
    "balance": 1000000,
    "percentage": 5.2,
    "role": {
      "class": "accumulator",
      "icon": "💎",
      "metal": "Diamond",
      "impact": "bullish"
    }
  }]
}
GET /token/:mint/candles/public No Auth

OHLCV candlestick data for charting.

Query Parameters:
resolution - 5, 60, or D (5min, 1hr, daily)
from - Start timestamp (unix ms)
to - End timestamp (unix ms)

Authenticated Endpoints

These endpoints require an API key. Higher rate limits and additional data.

GET /tokens API Key

Same as /tokens/public but with higher rate limits and full data access.

GET /token/:mint API Key

Full token details with integrity verification data.

GET /token/:mint/evolution API Key

K-Score history over time for trajectory analysis. Only available for verified tokens.

Query: days - 30, 60, or 90 (default: 30)
GET /token/:mint/verify API Key

Cryptographic integrity verification. Returns signature validation status.

GET /token/:mint/card.png No Auth

Generated K-Score card image (PNG). Perfect for social sharing.

GET /health No Auth

API health check. Returns service status, uptime, and memory usage.
